# llama.cpp b12177 bridge + React Native 0.88.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the RNLlamaCpp C++ bridge build and behave correctly on llama.cpp `b12177` using upstream's current APIs, then move the library and the bare example app to React Native 0.88.1 / React 19.3.0 (the RN that Expo SDK 58 ships).

**Architecture:**
- Text decode moves to upstream `common_batch` + `llama_process`, and chat moves to `common_chat_session`.
- Prompts are tokenized part by part (`common_chat_prompt`), so user text can never become control tokens.
- The common source list shrinks to what the bridge actually reaches.
- A new host-side C++ test binary (`cpp/tests/`) runs the JSI-free bridge (`rn-completion.cpp`, `rn-multimodal.cpp`) on macOS or Linux against upstream's vocab-only GGUFs and Jinja templates. An optional real model runs the end-to-end checks.

**Tech Stack:** C++20, llama.cpp `b12177` (`6c01da6278ab6c69ed67d9124806b50d2b299ba7`), CMake, CocoaPods, Gradle, React Native 0.88.1, Node 24, NDK r28c.

## Review Focus

1. **User types a control token** such as `<|im_end|>` into a chat message. It must stay plain text, and the token counts used for decoding and KV boundaries must agree. Tested in Task 2 (`tokenize_user_special_token_is_text`) and Task 3 (`chat_prompt_tokens_match_session`).
2. **User taps stop mid-ingest or mid-generation, then sends again.** The next answer must equal a fresh run, and the matched message prefix must not be re-encoded. Tested in Task 3 (`completion_abort_then_rerun_matches_fresh`, `chat_abort_keeps_matched_prefix`).
3. **A model's embedded Jinja template throws.** Chat must still work through the fallback levels. Tested in Task 3 (`session_fallback_on_broken_template`).
4. **Hybrid or recurrent model (for example Qwen3.5) fills the context.** It must stop cleanly instead of shifting. Tested in Task 3 (`completion_context_full_shift_or_stop`).
5. **Tool call on a specialized-parser template with a lazy grammar.** `tool_calls` must be parsed, not left as raw text. Tested in Task 3 (`session_parses_qwen35_tool_call`) and on device in Task 6.
